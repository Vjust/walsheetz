# Vite Configuration Files

This directory contains archived Vite configuration variants that were used during development experimentation.

## Current Configuration
The project uses a single `vite.config.js` at the root level to avoid confusion and maintain simplicity.

## Archived Configs
- `vite.config.simple.js` - Simplified configuration for basic builds
- `vite.config.minimal.js` - Minimal configuration with fewer plugins
- `vite.config.vanilla.js` - Vanilla configuration without React optimizations
- `vite.config.complex.js` - Complex configuration with additional build options
- `vite.config.js.backup` - Backup of previous configuration

These files are kept for reference but should not be used in development or production.
