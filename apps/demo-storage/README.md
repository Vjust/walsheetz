# Demo Storage App

Minimal demo application showcasing `@dreamlit/walrus` core storage SDK.

## Purpose

- Smoke test for Walrus storage operations
- Integration validation for browser and Node.js entry points
- Example usage patterns for consumers

## Planned Features

- File upload to Walrus
- File retrieval by blob ID
- Health check integration
- Retry mechanism demonstration

## Stack

- Vite + React
- TypeScript
- @dreamlit/walrus (production build)

**Status**: To be implemented in Phase 6
