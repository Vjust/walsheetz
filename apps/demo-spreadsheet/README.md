# Demo Spreadsheet App

Interactive demo for `@dreamlit/spreadsheet-sdk` showcasing spreadsheet functionality with Walrus integration.

## Purpose

- Smoke test for spreadsheet SDK components and hooks
- Integration validation with Walrus and Sui
- Reference implementation for consumers

## Planned Features

- Interactive spreadsheet with LuckySheet
- Auto-save to Walrus
- Formula evaluation
- CSV import/export
- Blockchain integration demonstration

## Stack

- Vite + React
- TypeScript
- @dreamlit/spreadsheet-sdk (production build)
- @tanstack/react-query

**Status**: To be implemented in Phase 6
