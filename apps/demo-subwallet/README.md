# Demo Sub-Wallet App

Example application demonstrating programmatic usage of `@walrus/subwallet-sdk` (not CLI).

## Purpose

- Smoke test for programmatic SDK API (not oclif CLI)
- Integration validation for wallet orchestration
- Example of SDK usage in Node.js applications

## Planned Features

- Wallet fleet initialization
- Parallel balance checks
- Batch funding operations
- Sponsored transaction workflows
- Rate limiting demonstration

## Stack

- Node.js
- TypeScript
- @walrus/subwallet-sdk (production build)

**Status**: To be implemented in Phase 6
